# 作者确认记录

2026-11-18，来源为本项目开发对话中作者的直接补充。以下记录功能关系和本轮默认配置；未包含新的实测通断、额定电流或端子物理排列证据。

## 主供电与“24V”含义

- 四芯主供电线缆的 1、2 为电池正极，3、4 为电池负极。
- 1/2 两线剥开、拧在一起并焊到同一个 LCB60 配插头的正极；3/4 同样合并接负极。正负两组保持分开。
- 电池展示图中有两个 LCB60 放电口。作者确认一个即可满足本机通流需求，当前接法使用一个，不要求把两个放电口并联；这不是连接器厂家额定电流的核验记录。
- 作者此前所称的所有“24V”供电均默认电池直接供电，电压随电池电量波动，不表示独立的恒定 24V 稳压电源。已收录电池参数的工作范围为 16.8–25.2 V，见[电池说明](../../hardware/electrical/battery-wiring.zh-CN.md)。具体保护板路径、支路保护和负载允许输入范围仍分别核对。

## 20P 水压计转接端子

20P 端子用于转接四只水压计的舱外插座与舱内供电、信号线。

| 功能 | 占用位数 | 连接关系 |
| --- | --- | --- |
| 24V / 电池正 | 4P | 四只压力计的同名线，用一个 4P 互联短接件连通 |
| GND / 电池负 | 4P | 四只压力计的同名线，用一个 4P 互联短接件连通 |
| 485A | 4P | 四只压力计的 A 线，用一个 4P 互联短接件连通 |
| 485B | 4P | 四只压力计的 B 线，用一个 4P 互联短接件连通 |
| 电力载波 | 2P | 载波线对分别转接 |
| 电池 CAN | 2P | CAN_H、CAN_L 分别转接 |

四个 4P 短接组彼此独立；PLC 两线和 CAN 两线各自保持独立，不因“占用 2P”而短接。作者明确 **20P 没有固定的端子顺序要求**，可按布线方便安排，记录实际采用的分组即可。四只压力计按既有位置使用不同 ID；表中顺序是功能分组，不是规定的实物端子编号。

压力计电源直接从电源控制板 EC-07 取电。通信路径为 **RoboMaster A 串口 → 串口转 RS-485 模块 → 20P 的 485A/485B 分组 → 四只压力计**；SUB 源码对应 UART8。模块型号、两侧物理端子及转换器本身供电仍待补，不把 MCU 的 TX/RX 直接写成 A/B。

[作者指定的 4P 端子互联短接件](https://item.taobao.com/item.htm?id=720074181347)。链接仅去掉追踪参数；本次无法读取商品页面，4P 规格来自作者说明，未核验间距、额定电流或适配型号。

## 18P 补光灯端子

三只补光灯的 24V 占 3P、GND 占 3P、PWM 占 3P，共占 9P；其余 9P 留空，由复刻者根据实际需求决定接线。作者确认 **三个灯各接一个独立 PWM 通道**，依据为 SUB 补光灯实例及 RoboMaster A BSP 的 PWM 通道定义，不将三路 PWM 短接。灯的空间位置与三个软件实例的对应、端子物理位号及电源端子的短接实现仍分别记录。

## EC-07 最终工程

作者确认 **最终 EDA 工程已经删除 R12**，最终版本不再装配该元件，原先“焊/不焊”的争议关闭。仓库旧交互式 BOM 仍含 R12，作为原附件保留，不能据它重新加装 R12；需从最终工程导出匹配的制板与装联文件，以更新发布包。

## 默认软件范围

嵌入式默认采用 `firmware/SUB/` 对应的 FineSUB SUB 分支，复刻目标先限定为手柄操控。配套使用原 SUB 转发链路；惯性里程计快照及 MAVLink 集成开发版保留为可选实验配置。此处“默认分支”是固件选型，不把本开源仓库的 Git 主分支 `main` 改名为 SUB。

仍需补充的输入、子任务和验收条件见[后续清单](remaining-work.zh-CN.md)。
